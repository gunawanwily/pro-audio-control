# Instal Android

1. Upload this PWA ke hosting HTTPS (GitHub Pages, Netlify, Vercel, atau web server HTTPS).
2. Buka URL aplikasi di Chrome Android.
3. Tekan tombol **⇩ Install** di aplikasi bila tersedia, atau menu Chrome → **Install app / Add to Home screen**.
4. Jalankan dari ikon **PRO AUDIO CONTROL**.

File audio yang dipilih tetap berasal dari perangkat.

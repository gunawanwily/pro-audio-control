# Instal iPhone / iPad

1. Upload PWA ke hosting **HTTPS**.
2. Buka URL menggunakan **Safari**.
3. Tekan **Share/Bagikan**.
4. Pilih **Add to Home Screen / Tambahkan ke Layar Utama**.
5. Tekan **Add/Tambahkan**.

Catatan: iOS memasang PWA sebagai web app. Tidak membutuhkan App Store untuk penggunaan PWA, tetapi beberapa kemampuan sistem tetap mengikuti batasan iOS/Safari.

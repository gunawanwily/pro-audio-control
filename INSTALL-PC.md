# Instal PC / Laptop

## Windows / macOS
1. Host aplikasi melalui HTTPS.
2. Buka di Chrome atau Edge.
3. Gunakan tombol **⇩ Install** atau menu browser **Install app**.
4. Aplikasi akan tampil sebagai jendela tersendiri tanpa address bar.

Untuk Windows, paket ini juga mempertahankan opsi Electron melalui `INSTALL-PRO-AUDIO-CONTROL.bat`.

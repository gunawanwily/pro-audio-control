PRO AUDIO CONTROL PWA v23.0

## Instalasi multiplatform

Satu paket PWA ini dapat dipasang pada:
- Android phone/tablet (Chrome)
- iPhone/iPad (Safari → Add to Home Screen)
- Windows laptop/PC (Chrome/Edge)
- macOS laptop (Chrome/Edge/Safari dengan dukungan PWA yang tersedia)

Aplikasi harus diakses melalui HTTPS agar service worker dan instalasi PWA bekerja penuh. Untuk pengujian lokal, gunakan `RUN-PWA-LOCAL.bat`.

Panduan terpisah:
- `INSTALL-ANDROID.md`
- `INSTALL-IOS.md`
- `INSTALL-PC.md`

## Fitur yang dipertahankan
12 Audio Pads, Add Music per pad, drag & drop audio, edit nama pad, volume per pad, Master Volume, Fade In/Out, auto crossfade antar pad, loop persisten dengan gradasi/glow, visualizer per pad, countdown, Music Player dengan playlist scroll + drag reorder + X delete, seek slider, STOP, CLEAR ALL, 5 skin, dan responsive touch UI.
